# Plan d’amélioration des matériaux live V18

- **Baseline source Sync-4 auditée** : `shared/Chamagnieu_V18_REALISM_FINAL_WEBP.glb` — `35` matériaux avant correction.
- **Candidat Web Realism produit** : `shared/Chamagnieu_V18_WEB_REALISM_UPGRADED.glb` — `41` matériaux après ajout des six matériaux V18 dédiés.
- **SHA-256 source** : `69F10EC076B68968CA91F0412481956F5CE0E1DE972ECB5E25CBF69990306DDE`
- **Périmètre** : les lignes `[0]` à `[34]` décrivent la baseline Sync-4 et l’action prévue/appliquée; les lignes `[35]` à `[40]` décrivent les six matériaux ajoutés dans le GLB amélioré. L’audit couvre donc les `41/41` matériaux du candidat, sans hypothèse Blender/D5.
- **Principe d’exécution** : conserver les 2 454 accessors et leurs payloads géométriques byte-identiques sémantiquement, embarquer les nouveaux WebP, retirer les 11 images remplacées et leurs payloads, ne créer aucune URI externe et ne réaffecter que les meshes nommés.
- **Végétation live** : les nœuds low-poly `V17_HEDGE_LIGHT_*` et `V17_TREE_LIGHT_*` restent embarqués dans le GLB comme fallback. Sur le chemin runtime `enhanced`, `shared/live-vegetation.js` charge `shrub_03_web.glb` et `island_tree_02_web.glb`, puis masque les originaux seulement après le chargement réussi de leur remplacement. Les appareils contraints ou un échec de chargement conservent les matériaux fallback du GLB.

## Limites explicites

- La géométrie low-poly des haies et des arbres est conservée dans le GLB amélioré pour fournir un fallback déterministe. Sur un appareil normal, le runtime enhanced charge les assets optimisés, masque ensuite les originaux V17 et affiche `V18_REAL_HEDGE_*` / `V18_REAL_TREE_*`; en mode économie de données, mémoire contrainte ou échec réseau, les originaux et les six matériaux documentés restent visibles.
- `PBR_B_WOOD`, `V12_PBR_BEIGE_COTTON` et les deux matériaux V17 étaient partagés entre usages incompatibles; le build duplique uniquement les matières nécessaires et réaffecte 37 bindings de primitives, sans changer les meshes.
- Le tiling repose sur les UV présents. Les réglages indiqués privilégient la distance moyenne et évitent une texture 4K supplémentaire.
- Les matériaux secondaires plats (`V10_SILL_STONE`, `V11_COUNTER_STONE`, portes et cuisine laquée) restent candidats à une passe ultérieure; ils ne doivent pas diluer la priorité façade/sols/végétation/mobilier principal.
- Le vitrage physique exige un environnement de réflexion et un tone mapping cohérents côté viewer; ces réglages appartiennent à l’audit éclairage séparé.
